# DaniTools
DaniTools는 심플하고 강력한 POLO LAUNCHER 기반 프로그램입니다.(POLO LAUNCHER의 커밋 8df2852까지 일부 참조)

<details>
<summary>Shell</summary>

---

```bash
cls
```
콘솔을 비웁니다.

---

```bash
echo <문자>
```
`<문자>`에 입력된 값을 그대로 출력합니다. 메아리라고 생각하시면 편합니다.
